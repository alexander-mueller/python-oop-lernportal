Python als Taschenrechner 🧮

Lerne die Grundrechenarten, besondere Operatoren wie Modulo und Ganzzahldivision sowie Punkt-vor-Strich-Regeln in Python kennen.

📂 Dateien dieser Einheit:
📄 aufgabe.py (Startercode) 🧪 test_aufgabe.py (Tests) 💡 musterloesung.py (Lösung) 📖 README.md

1. Die Taschenrechner-Analogie 💡

Bevor wir riesige Programme und Klassen bauen, starten wir mit der einfachsten Eigenschaft von Python: Python ist der schnellste und präziseste Taschenrechner der Welt!

🧠 Warum ist Python besser als ein gewöhnlicher Taschenrechner?
Ein normaler Taschenrechner hat oft ein Limit bei 10 oder 12 Stellen. Python hingegen rechnet mit beliebig großen Zahlen (sogar Zahlen mit hunderten Ziffern!) und verarbeitet komplexe mathematische Formeln fehlerfrei nach den universellen Rechengesetzen.
Python Interaktiv (REPL / Terminal) 
# Einfach eintippen – Python rechnet sofort:
>>> 12 + 8
20

>>> 100 * 5
500

>>> 2 ** 10  # 2 hoch 10
1024

2. Ganze Zahlen (int) vs. Kommazahlen (float)

In Python gibt es zwei fundamentale Typen von Zahlen:

🔢 Die zwei Zahlenwelten:
  • int (Integer): Ganze Zahlen ohne Nachkommastellen (z.B. 42, -7, 0, 1000000).
  • float (Floating Point): Kommazahlen mit Nachkommastellen (z.B. 3.14, -0.5, 2.0).
⚠️ Wichtig: Punkt statt Komma!
Im Deutschen schreiben wir 3,14 mit Komma. Im Programmieren gilt immer der angelsächsische Punkt: 3.14. Ein Komma in Python trennt Parameter oder Listenelemente!

3. Die 7 Rechenoperatoren im Überblick

Hier sind alle wichtigen mathematischen Operatoren, die du in Python beherrschen musst:

Operator Name Beispiel Ergebnis Erklärung & Besonderheit
+ Addition 12 + 8 20 Addiert zwei Werte
- Subtraktion 20 - 7 13 Zieht den zweiten Wert ab
* Multiplikation 6 * 7 42 Multipliziert zwei Werte
/ Echte Division 7 / 2 3.5 Wichtig: Liefert in Python 3 immer ein float (Kommazahl)! Sogar 4 / 2 liefert 2.0.
// Ganzzahldivision 17 // 5 3 Rundet das Ergebnis immer zur nächsten ganzen Zahl nach unten ab (Floor Division).
% Modulo (Rest) 17 % 5 2 Gibt den Rest bei der Ganzzahldivision zurück.
** Potenzierung 2 ** 3 8 Berechnet Basis hoch Exponent (2 * 2 * 2 = 8).

🍕 Die Pizza-Analogie für // und %

17 Pizzastücke auf 5 Freunde aufteilen:

- 17 // 5 = 3 → Jeder Freund bekommt genau 3 ganze Stücke.
- 17 % 5 = 2 → In der Schachtel bleiben 2 Stücke übrig.
- Kontrollrechnung: \(3 \times 5 + 2 = 17\) Stücke!

4. Vorrangregeln: Punkt vor Strich & Klammern 📐

Python hält sich streng an die mathematischen Rechengesetze (PEMDAS):

  1. Klammern (...): Höchste Priorität – wird immer zuerst ausgewertet!
  2. Potenzen **: Werden vor Punkt- und Strichrechnung ausgeführt.
  3. Punktrechnung *, /, //, %: Kommt vor Strichrechnung.
  4. Strichrechnung +, -: Wird zuletzt ausgeführt.
Vergleich: Vorrangregeln 
# Ohne Klammer: 3 * 4 = 12, dann 2 + 12 = 14
a = 2 + 3 * 4        # 14

# Mit Klammer: (2 + 3) = 5, dann 5 * 4 = 20
b = (2 + 3) * 4      # 20

# Kreisflächen-Formel: pi * r²
flaeche = 3.14159 * (radius ** 2)

5. Erste Textausgaben mit print() 📢

Mit der eingebauten Python-Funktion print() gibst du Texte und Rechenergebnisse auf der Konsole aus:

Beispiele für print()
print("Hallo Welt!")
print("Das Ergebnis von 5 + 3 ist:", 5 + 3)

# Modern mit f-String:
radius = 5
flaeche = 3.14159 * (radius ** 2)
print(f"Kreis mit Radius {radius} hat die Fläche: {flaeche}")

return (a // b, a % b)
