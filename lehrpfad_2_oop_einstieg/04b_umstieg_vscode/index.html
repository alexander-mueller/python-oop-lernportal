Installation & Setup

Umstieg von Thonny auf Visual Studio Code 🚀💻

Schritt-für-Schritt-Installationsanleitung (Windows, Mac, Linux), die besten Plugins und Profi-Tipps.

1. Warum wechseln wir von Thonny zu VS Code?

Thonny war für den Einstieg super: Es ist schlank und man sieht Variablen sofort.

Aber ab jetzt werden unsere Projekte größer (mehrere Dateien, Klassen, Tests und Git). Visual Studio Code (VS Code) von Microsoft ist die weltweit beliebteste Entwicklungsumgebung für Python.

🏎️ Die 4 größten Vorteile von VS Code:
  • IntelliSense: Schlägt dir automatisch Methoden und Attribute vor (z.B. wenn du mein_auto. tippst).
  • Projekt-Explorer: Alle Dateien und Ordner deines Kurses auf einen Blick.
  • Integriertes Terminal: Skripte und Tests direkt im Editor mit Strg + ` ausführen.
  • Erweiterungen (Extensions): Fehler werden direkt farbig im Code markiert (Error Lens).

2. 📥 Schritt-für-Schritt Installationsanleitung

Wähle dein Betriebssystem aus und befolge die Schritte:

🪟 Anleitung für Windows 10 / 11
  1. Gehe auf die offizielle Website: code.visualstudio.com und klicke auf den blauen Button "Download for Windows".
  2. Starte die heruntergeladene Installationsdatei (VSCodeUserSetup-x64-...exe).
  3. Akzeptiere die Lizenzvereinbarung und klicke auf Weiter.
  4. ⚠️ Sehr wichtig bei der Windows-Installation:
    Setze im Schritt "Zusätzliche Aufgaben auswählen" unbedingt alle Haken:
    • ✓ Aktion "Mit Code öffnen" zum Windows Explorer-Dateikontextmenü hinzufügen
    • ✓ Aktion "Mit Code öffnen" zum Windows Explorer-Verzeichniskontextmenü hinzufügen
    • ✓ Code als Editor für unterstützte Dateitypen registrieren
    • ✓ Zu PATH hinzufügen (nach Neustart verfügbar)
  5. Klicke auf Installieren und danach auf Fertigstellen (VS Code startet automatisch).
🍎 Anleitung für macOS (MacBook / iMac)
  1. Gehe auf code.visualstudio.com und lade "Download for Mac" herunter (Universal).
  2. Öffne deinen Downloads-Ordner und entpacke die .zip-Datei (falls nicht automatisch geschehen).
  3. 💡 Wichtig für Mac-Nutzer:
    Ziehe die Datei Visual Studio Code aus dem Downloads-Ordner in deinen Ordner Programme (Applications)!
  4. Öffne VS Code aus dem Programme-Ordner. (Falls eine Warnung erscheint: Klicke auf "Öffnen").
🐧 Anleitung für Linux (Ubuntu / Debian / Mint)

Lade das .deb-Paket von code.visualstudio.com herunter und doppelklicke darauf, oder installiere es direkt per Terminal:

sudo apt update && sudo apt install snapd
sudo snap install --classic code
🇩🇪 Sprache auf Deutsch umstellen (Optional):
Wenn du VS Code auf Deutsch haben möchtest:
  1. Drücke Strg + Shift + P (Mac: Cmd + Shift + P).
  2. Tippe: Configure Display Language und drücke Enter.
  3. Wähle Deutsch (German) aus. VS Code startet kurz neu und ist komplett auf Deutsch!

3. 📁 Das Projekt in VS Code öffnen

⚠️ Grundregel: Immer "Ordner öffnen", nicht nur eine Datei!
In VS Code öffnet man immer den gesamten Hauptordner (Aufgaben-Python), damit alle Kapitel, Hilfsdateien und Tests auf einmal verknüpft sind.
  1. Klicke oben im Menü auf Datei → Ordner öffnen... (Mac: File → Open Folder...).
  2. Wähle deinen Ordner Aufgaben-Python aus und klicke auf Ordner auswählen.
  3. Bestätige die Meldung "Vertrauen Sie den Autoren dieser Dateien?" mit Ja.

Jetzt siehst du links in der Leiste den gesamten Dateibaum aller Kapitel!

4. 🧩 Die wichtigsten Erweiterungen (Plugins)

Klicke ganz links in der Seitenleiste auf das Erweiterungs-Icon (die 4 Kacheln) oder drücke Strg + Shift + X (Mac: Cmd + Shift + X).

Suche nach den folgenden Namen und klicke jeweils auf Installieren (Install):

🐍

1. Python (von Microsoft)

Pflicht! Aktiviert Syntax-Hervorhebung, Code-Ausführung und IntelliSense.

⚡

2. Pylance (von Microsoft)

Macht die Autovervollständigung blitzschnell und warnt bei falschen Parametern.

🔍

3. Error Lens Must-Have!

Zeigt Fehler direkt farbig in der Codezeile an – du musst nicht lange suchen!

🎨

4. Material Icon Theme

Gibt allen Dateien im Explorer schöne, bunte Symbole (Python-Logo, HTML-Icon etc.).

💬

5. Better Comments

Färbt Kommentare ein: # TODO (orange), # ! (rot), # ? (blau).

🪄

6. Black Formatter

Formatiert Code beim Speichern (Strg+S) automatisch perfekt.
