# Git 03: Diff-Analysen & Änderungen untersuchen

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Untersuche Unstaged vs. Staged Änderungen und vergleiche Commits präzise.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Arbeitsverzeichnis mit Staging-Area vergleichen (git diff)
2. **Teilziel 2:** Staging-Area mit HEAD vergleichen (git diff --staged)
3. **Teilziel 3:** Änderungen eines spezifischen Commits mit git show anzeigen
4. **Teilziel 4:** Statistiken mit git diff --stat auswerten
