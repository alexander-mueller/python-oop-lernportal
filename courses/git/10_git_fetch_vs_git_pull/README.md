# Git 10: Git Fetch vs. Git Pull & Rebase

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Sichere Synchronisation: Erst inspizieren (fetch), dann integrieren (pull --rebase).
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Remote-Metadaten sicher abrufen mit git fetch origin
2. **Teilziel 2:** Unterschiede zwischen origin/main und lokalem main analysieren
3. **Teilziel 3:** Änderungen mit git pull --rebase sauber integrieren
4. **Teilziel 4:** Divergierende Branches synchronisieren
