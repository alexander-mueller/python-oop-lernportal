# Git 14: Interaktives Rebase (Squash & Fixup)

## 💡 Das Wichtigste in Kürze
- **Ziel:** Polierte Commit-Historie vor dem Pull-Request: Mehrere kleine 'WIP'-Commits zusammenfassen.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Interaktiven Rebase für die letzten 3 Commits starten (git rebase -i HEAD~3)
2. **Teilziel 2:** Commits mit 'squash' oder 'fixup' zusammenfassen
3. **Teilziel 3:** Commit-Nachricht mit 'reword' präzisieren
4. **Teilziel 4:** Saubere, aussagekräftige Historie prüfen
