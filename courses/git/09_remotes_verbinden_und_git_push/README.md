# Git 09: Remote Repositories & Upstream Tracking

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Verbinde dein lokales Repository mit Remote-Servern (GitHub, GitLab, internes Git).
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Remote mit git remote add origin hinzufügen
2. **Teilziel 2:** Upstream-Tracking mit git push -u origin main etablieren
3. **Teilziel 3:** Remote-URLs mit git remote -v prüfen
4. **Teilziel 4:** Remote-Informationen mit git remote show origin abrufen
