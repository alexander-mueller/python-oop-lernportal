# Git 11: Release-Tags & Semantische Versionierung

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Kennzeichne Software-Releases nach SemVer (v1.0.0, v1.1.0) mit annotierten Tags.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Annotierten Tag mit git tag -a v1.0.0 -m 'Release 1.0.0' erstellen
2. **Teilziel 2:** Tags auflisten und filtern (git tag -l 'v1.*')
3. **Teilziel 3:** Tag-Details mit git show v1.0.0 inspizieren
4. **Teilziel 4:** Tags zum Remote übertragen (git push origin --tags)
