# Git 04: .gitignore & Ausschlussregeln

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Halte Repositories sauber von Build-Artefakten, Passwörtern (.env) und OS-Dateien.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** .gitignore mit Wildcard-Patterns (*.log, temp/) anlegen
2. **Teilziel 2:** Ausnahmeregel mit Ausrufezeichen (!keep.log) definieren
3. **Teilziel 3:** Versehentlich getrackte Datei mit git rm --cached aus dem Index entfernen
4. **Teilziel 4:** Ignorierregeln mit git check-ignore validieren
