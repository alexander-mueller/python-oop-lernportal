# Git 12: Selektive Commits mit Git Cherry-Pick

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Übertrage einzelne, wichtige Commits (z.B. Security-Patches) isoliert zwischen Branches.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Commit-Hash des Bugfixes im Feature-Branch ermitteln
2. **Teilziel 2:** Auf Release-Branch wechseln und commit mit git cherry-pick <hash> anwenden
3. **Teilziel 3:** Cherry-Pick Konflikt auflösen und abschließen
4. **Teilziel 4:** Historie beider Branches vergleichen
