# Git 13: Lineare Historie mit Git Rebase

Willkommen zum Kurs **Git Versionskontrolle & DevOps Workflows** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Halte Projekt-Historien linear und übersichtlich durch kontrolliertes Rebasing.
- **Wichtigste Befehle:** `git status`, `git add`, `git commit`, `git switch`, `git log`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Feature-Branch auf den aktuellen main-Branch rebasen
2. **Teilziel 2:** Die 'Golden Rule of Rebasing' beachten (kein Rebase auf public branches)
3. **Teilziel 3:** Fast-Forward Merge nach erfolgreichem Rebase durchführen
4. **Teilziel 4:** Unterschiede zwischen Merge-Graph und Rebase-Historie analysieren
