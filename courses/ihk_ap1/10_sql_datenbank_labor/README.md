# AP1 08: Relationale Datenbanken, ERM & SQL (LF 5.4)

Software zur Verwaltung von Daten: Entity-Relationship-Modelle (ERM in Krähenfuß-Notation), 1:1, 1:n, n:m Relationen, Primär- und Fremdschlüssel, SQL DDL (CREATE TABLE), DML (INSERT, UPDATE, DELETE) und DQL (SELECT, WHERE, ORDER BY, GROUP BY, HAVING, INNER/LEFT JOIN).
