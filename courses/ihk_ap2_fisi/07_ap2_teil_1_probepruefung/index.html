1. Aufgabe: VDI, Thin Clients & Gruppenrichtlinien

25 Punkte

Ein Unternehmen plant die Ablösung klassischer Desktop-PCs durch eine Virtual Desktop Infrastructure (VDI) mit zentralem Server-Cluster und Thin Clients.

Offizielle IHK-Musterlösung:

a) (6 Pkt.): 1. Zentrale Administration, Rollout und Patchmanagement am Server; 2. Geringere Hardware- und Energiekosten an den Endgeräten (Thin Clients brauchen wenig Strom); 3. Höhere Datensicherheit, da keine Unternehmensdaten lokal auf den Clients gespeichert werden.
b) (10 Pkt.): Active Directory Gruppenrichtlinien (GPOs). Verarbeitungsreihenfolge: Lokal → Site (Standort) → Domain (Domäne) → OU (Organisationseinheit). Die unterste OU überschreibt übergeordnete Richtlinien, es sei denn, eine Richtlinie ist auf 'Erzwungen' (Enforced) gesetzt.
c) (9 Pkt.): RDP (Remote Desktop Protocol), VMware Blast Extreme oder Teradici PCoIP. Bandbreitenbedarf ca. 1,5 bis 3 Mbit/s pro Office-User, bei Multimedia/Video bis zu 5-10 Mbit/s mit niedriger Latenz (< 50 ms).

2. Aufgabe: Symmetrische Verschlüsselung & Integrität

22 Punkte

Zur Sicherung von Backup-Dateien und Festplatten-Images werden Verschlüsselungsverfahren eingesetzt.

Offizielle IHK-Musterlösung:

a) (6 Pkt.): Vertraulichkeit: Daten können nur von autorisierten Personen gelesen werden. Integrität: Daten wurden nicht unbemerkt manipuliert oder beschädigt. Authentizität: Der Urheber/Absender ist zweifelsfrei nachgewiesen.
b) (16 Pkt.): DES nutzt eine effektive Schlüssellänge von lediglich 56 Bit. Ein 56-Bit-Schlüssel kann mit moderner Rechenleistung in wenigen Stunden per Brute-Force-Angriff geknackt werden. AES bietet Schlüssellängen von 128, 192 oder 256 Bit. 3. Aufgabe: PowerShell / Python Server-Monitoring-Skript

27 Punkte

Ein Array stundenWerte enthält 24 stündliche CPU-Auslastungswerte (0 bis 23 Uhr) eines Servers. Schreibe ein Skript oder Pseudocode, das:
1. Den Mittelwert des gesamten Tages berechnet,
2. Den Mittelwert des Vormittags (Stunden 0 bis 11) berechnet,
3. Den Mittelwert des Nachmittags (Stunden 12 bis 23) berechnet,
4. Eine Warnung ausgibt, falls ein Mittelwert > 80% liegt. (27 Punkte)

Offizielle IHK-Musterlösung:

int sumGesamt = 0; int sumVormittag = 0; int sumNachmittag = 0;
for (int i = 0; i < 24; i++) {
    sumGesamt += stundenWerte[i];
    if (i < 12) { sumVormittag += stundenWerte[i]; }
    else { sumNachmittag += stundenWerte[i]; }
}
double mwGesamt = sumGesamt / 24.0;
double mwVormittag = sumVormittag / 12.0;
double mwNachmittag = sumNachmittag / 12.0;

if (mwGesamt > 80 || mwVormittag > 80 || mwNachmittag > 80) {
    print("WARNUNG: Hohe Serverauslastung festgestellt!");
}

4. Aufgabe: Backup-Wiederherstellung & Compliance

26 Punkte

Ein Unternehmen sichert sonntags eine Vollsicherung (V1 bis V5) und montags bis samstags differenzielle Sicherungen (D1 bis D6). Am Donnerstag fällt das System aus.

Offizielle IHK-Musterlösung:

a) (12 Pkt.): Es werden nur 2 Bänder benötigt:
1. Die letzte Vollsicherung vom Sonntag.
2. Die letzte differenzielle Sicherung vom Mittwochabend (enthält alle Änderungen seit Sonntag).
(Hinweis: Bei inkrementeller Sicherung hätte man alle Bänder So, Mo, Di, Mi gebraucht!)
b) (14 Pkt.): WORM (Write Once Read Many) verhindert technisch jede nachträgliche Veränderung, Manipulation oder vorzeitige Löschung der Daten nach dem ersten Schreibvorgang. Dies erfüllt die rechtlichen Vorgaben zur revisionssicheren Archivierung nach GoBD und HGB.
