🗄️ Enterprise SQL & Datenbank-Administration (LF 10 & 11)

Offizieller ZPA 2. Auflage Standard: Alle SQL-Befehle (DDL, DML, DCL, Joins, Unterabfragen und spezifische ZPA-Funktionen wie DATEDIFF) wurden aus AP1 entfernt und sind nun exklusiv in der AP2 verortet!

1. DDL: Tabellenstruktur & Constraints

CREATE TABLE mitarbeiter (
    mit_nr INTEGER PRIMARY KEY,
    nachname VARCHAR(50) NOT NULL,
    vorname VARCHAR(50) NOT NULL,
    gehalt DECIMAL(10,2) CHECK (gehalt > 0),
    eintrittsdatum DATE NOT NULL,
    abt_nr INTEGER,
    CONSTRAINT fk_abt FOREIGN KEY (abt_nr) 
        REFERENCES abteilung(abt_nr) ON DELETE RESTRICT
);

-- Tabellenstruktur nachträglich ändern
ALTER TABLE mitarbeiter ADD COLUMN email VARCHAR(100);
ALTER TABLE mitarbeiter MODIFY COLUMN nachname VARCHAR(80);
ALTER TABLE mitarbeiter DROP COLUMN email;

2. DCL: Benutzer- & Rechteverwaltung

-- Benutzer anlegen & Rechte vergeben
CREATE USER 'reporting'@'localhost' IDENTIFIED BY 'Start2025!Secure';
GRANT SELECT, INSERT ON unternehmen.* TO 'reporting'@'localhost' WITH GRANT OPTION;
REVOKE INSERT ON unternehmen.* FROM 'reporting'@'localhost';

3. Multi-Table JOINs, Aggregation & ZPA-Funktionen

- JOINs: INNER JOIN (nur übereinstimmende Paare), LEFT JOIN (alle Zeilen der linken Tabelle, auch ohne Treffer rechts).
- Datumsdifferenz: DATEDIFF(end_datum, start_datum) berechnet Tage zwischen Daten.
- GROUP BY & HAVING: SELECT abt_nr, AVG(gehalt) FROM mitarbeiter GROUP BY abt_nr HAVING COUNT(*) >= 5;
- ACID: Atomicity (Alles oder Nichts), Consistency (Konsistenz), Isolation (Transaktionsisolierung), Durability (Dauerhaftigkeit).
