⚙️ Skriptprogrammierung & Systemautomation (LF 10)

Gemäß § 21 Abs. 1 Nr. 4 der Ausbildungsordnung und ZPA-Katalog S. 22/24 müssen Systemintegratoren in der Lage sein, Programme zur automatisierten Systemverwaltung in PowerShell, Bash und Python zu erstellen.

1. Microsoft PowerShell: Objektorientierte Pipeline & AD-Automation

Im Gegensatz zu traditionellen Text-Pipes übergibt PowerShell echte .NET-Objekte mit typisierten Eigenschaften:

# Automatisiertes Onboarding aus CSV mit Fehlerbehandlung
$ErrorActionPreference = 'Stop'
try {
    $users = Import-Csv -Path "C:\Temp\azubis.csv" -Delimiter ";"
    foreach ($u in $users) {
        $secPass = ConvertTo-SecureString "Start2025!" -AsPlainText -Force
        New-ADUser -Name "$($u.Vorname) $($u.Nachname)" `
                   -SamAccountName $u.Login `
                   -UserPrincipalName "$($u.Login)@unternehmen.local" `
                   -Path "OU=Azubis,OU=Benutzer,DC=unternehmen,DC=local" `
                   -AccountPassword $secPass `
                   -Enabled $true
        Write-Host "✓ Angelegt: $($u.Login)" -ForegroundColor Green
    }
} catch [Exception] {
    Write-Error "Kritischer Fehler bei Benutzeranlage: $($_.Exception.Message)"
}

2. Linux Bash-Automatisierung & Systemd Service Units

- Robuste Shell-Skripte: set -euo pipefail (bricht sofort bei unbehandelten Fehlern oder ungesetzten Variablen ab).
- Systemd Unit-Datei (z. B. /etc/systemd/system/backup.service): 

[Unit]
Description=Tägliches Backup-Skript für Unternehmensdaten
After=network.target

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup_rsync.sh
User=root

[Install]
WantedBy=multi-user.target

3. Infrastruktur-Automatisierung mit Ansible & IaC

- Ansible: Agentless über SSH. Deklarative YAML-Playbooks definieren den Soll-Zustand (Idempotenz).
- Infrastructure as Code (IaC): Reproduzierbare Bereitstellung ganzer Serverlandschaften (z. B. mit Terraform oder Cloud-Init) vermeidet manuelle Konfigurationsdrifts.
