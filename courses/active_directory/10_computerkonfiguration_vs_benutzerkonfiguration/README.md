# AD 10: Computer- vs. Benutzerkonfiguration & Loopback

Willkommen zum Kurs **Active Directory & Windows Server Administration** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Unterschied Computer- vs. Benutzerkonfiguration und Loopback-Verarbeitungsmodus (Merge vs. Replace).
- **Wichtigste Cmdlets / Tools:** `Set-GPOLoopbackPolicy`, `Get-ADUser`, `Get-ADGroup`, `New-ADOrganizationalUnit`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Computereinstellungen (BitLocker, Windows Defender) definieren
2. **Teilziel 2:** Benutzereinstellungen (Desktop, Netzlaufwerke, Startmenü) anpassen
3. **Teilziel 3:** Loopback-Verarbeitung für Terminalserver (RDS) aktivieren
4. **Teilziel 4:** Unbenutzte GPO-Hälften zur Performance-Optimierung deaktivieren
