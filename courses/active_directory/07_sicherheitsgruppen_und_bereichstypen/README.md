# AD 07: Sicherheitsgruppen & Bereichstypen

Willkommen zum Kurs **Active Directory & Windows Server Administration** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Bereichstypen (Global, Domain Local, Universal), Sicherheits- vs. Verteilergruppen und Token-Größe.
- **Wichtigste Cmdlets / Tools:** `New-SecurityGroupHierarchy`, `Get-ADUser`, `Get-ADGroup`, `New-ADOrganizationalUnit`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Globale Benutzergruppen (GG_) und Lokale Ressourcengruppen (DLG_) anlegen
2. **Teilziel 2:** Mitglieder mit Add-ADGroupMember zuweisen
3. **Teilziel 3:** Rekursive Gruppenmitgliedschaften analysieren (Get-ADGroupMember -Recursive)
4. **Teilziel 4:** Gruppenbereich (GroupScope) konvertieren
