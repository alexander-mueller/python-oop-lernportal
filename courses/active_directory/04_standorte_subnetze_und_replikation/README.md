# AD 04: Standorte, Subnetze & Replikation

Willkommen zum Kurs **Active Directory & Windows Server Administration** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** AD-Standorte (Sites), IP-Subnetze, Site Links, Replikationstopologie (KCC) und Replikationszeitpläne.
- **Wichtigste Cmdlets / Tools:** `Sync-ADReplicationSite`, `Get-ADUser`, `Get-ADGroup`, `New-ADOrganizationalUnit`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Neuen AD-Standort mit New-ADReplicationSite erstellen
2. **Teilziel 2:** IP-Subnetz dem Standort zuweisen (New-ADReplicationSubnet)
3. **Teilziel 3:** Site Link mit Kosten (Cost) und Replikationsintervall anlegen
4. **Teilziel 4:** Replikationsstatus mit repadmin /replsummary prüfen
