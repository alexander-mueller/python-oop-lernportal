# AD 12: GPO Troubleshooting: gpupdate & gpresult

Willkommen zum Kurs **Active Directory & Windows Server Administration** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze
- **Ziel:** Richtlinien-Diagnose: gpupdate /force, gpresult /r, HTML-Berichte und Konflikt-Analyse.
- **Wichtigste Cmdlets / Tools:** `Invoke-GPODiagnostics`, `Get-ADUser`, `Get-ADGroup`, `New-ADOrganizationalUnit`

## 🎯 Deine Aufgaben (Checkliste)
1. **Teilziel 1:** Sofortige Aktualisierung mit gpupdate /force erzwingen
2. **Teilziel 2:** Angewandte GPOs im Terminal mit gpresult /r auswerten
3. **Teilziel 3:** Detaillierten HTML-Ergebnisbericht mit Get-GPOReport generieren
4. **Teilziel 4:** Fehlerhafte oder abgelehnte Richtlinien identifizieren
