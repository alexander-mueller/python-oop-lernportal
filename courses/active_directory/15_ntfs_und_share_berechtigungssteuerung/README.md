# AD 15: NTFS- & Share-Berechtigungssteuerung

Willkommen zum Kurs **Active Directory & Windows Server Administration** im IT-Praxisportal!

## 💡 Das Wichtigste in Kürze

- **Wichtigste Cmdlets / Tools:** `Set-ShareAndNtfsSecurity`, `Get-ADUser`, `Get-ADGroup`, `New-ADOrganizationalUnit`

2. **Teilziel 2:** Freigabeberechtigungen (Full Control für Domänen-Admins) setzen
3. **Teilziel 3:** NTFS-ACLs mit Get-Acl und Set-Acl konfigurieren
4. **Teilziel 4:** Vererbung deaktivieren und explizite Berechtigungen setzen
