💡 1. REST-APIs & JSON-Pipelines

PowerShell ist von Haus aus objektorientiert. Bei Aufruf von Invoke-RestMethod wird die empfangene JSON-Nutzlast automatisch in navigierbare .NET-Objekte umgewandelt. 

# REST-API Abfrage mit Bearer-Token
$headers = @{
    Authorization = "Bearer $apiSecret"
}
$nodes = Invoke-RestMethod -Uri "https://api.cloud.corp/v1/nodes" -Headers $headers -Method GET

# JSON Export ohne Datenverlust:
$jsonConfig = $nodes | ConvertTo-Json -Depth 10

⚠️ Achtung: Der -Depth Parameter!

Standardmäßig schneidet ConvertTo-Json Objekte ab der 2. Ebene ab. Gib bei verschachtelten Objekten immer explizit -Depth 10 (oder höher) an!

🏛️ 2. Datenformate im DevOps-Alltag

🌐 JSON

ConvertFrom-Json / ConvertTo-Json
Ideal für Cloud-APIs, Microservices und moderne Webhooks.

📊 CSV

Import-Csv / Export-Csv -NoTypeInformation
Perfekt für Auditing-Tabellen, Excel-Reports und Massendaten.

📑 XML

[xml]$doc = Get-Content
Für Legacy-Konfigurationen, Gruppenrichtlinien und SOAP-Dienste.
