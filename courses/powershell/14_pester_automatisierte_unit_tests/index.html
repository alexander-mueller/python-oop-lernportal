💡 1. Pester v5 Testing Framework

Pester v5 trennt Discovery- und Run-Phase strikt und ermöglicht testgetriebene Entwicklung (TDD) für Enterprise PowerShell Skripte: 

Describe 'Get-ServerHealthStatus' {
    It 'Sollte Operational melden, wenn Dienst läuft' {
        Mock Get-Service { [PSCustomObject]@{ Status = 'Running' } }
        Mock Test-Connection { $true }

        $res = Get-ServerHealthStatus -ServerName 'srv-web01'
        $res.IsHealthy | Should -BeTrue
    }
}

🏛️ 2. Die Kernkonzepte von Pester v5

1. BDD Struktur

Describe, Context und It für sprechende, lesbare Testfälle im Team.

2. Fluent Should

Should -Be, Should -Throw, Should -HaveCount für eindeutige Zusicherungen.

3. Cmdlet Mocking

Mock & Should -Invoke zum Testen gefährlicher Aktionen ohne Seiteneffekte auf Realsysteme.
