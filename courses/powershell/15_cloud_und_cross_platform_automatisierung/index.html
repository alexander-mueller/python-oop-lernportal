💡 1. Multi-Cloud & Cross-Platform DevOps

PowerShell 7+ läuft nativ auf Linux und im Docker-Container. Es verbindet APIs von Azure (Az-Modul), AWS und On-Premises zu einem einheitlichen Automatisierungs-Workflow: 

# Plattform-Erkennung
if ($IsLinux) {
    Write-Host "Ausführung im Linux-Container: $($PSVersionTable.OS)"
}

# AWS CLI JSON-Pipeline
$vms = (aws ec2 describe-instances | ConvertFrom-Json).Reservations.Instances
