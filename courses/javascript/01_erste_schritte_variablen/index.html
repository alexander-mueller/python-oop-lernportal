JS 01: Variablen, Typen & Template-Strings

Lerne die Grundlagen der modernen Web-Entwicklung mit let, const und Template-Strings.

💡 1. Variablen in modernem JavaScript

In modernem JavaScript (ES6+) deklarieren wir Variablen mit const (unveränderlich) oder let (veränderbar). Das alte var sollte vermieden werden.

const name = "Anna";
let punkte = 100;
punkte += 25;

// Template-Strings mit Backticks:
const text = `Hallo ${name}, du hast ${punkte} Punkte!`;
console.log(text);
