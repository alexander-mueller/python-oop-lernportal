JS 02: Arrow Functions, Arrays & Map/Filter

Lerne funktionale Array-Transformationen mit .map(), .filter() und .reduce().

💡 1. Moderne Array-Methoden in JavaScript

Statt klassischer for-Schleifen nutzen wir funktionale Methoden:

const zahlen = [1, 2, 3, 4];
const verdoppelt = zahlen.map(x => x * 2);
const gerade = zahlen.filter(x => x % 2 === 0);
const summe = zahlen.reduce((a, b) => a + b, 0);
