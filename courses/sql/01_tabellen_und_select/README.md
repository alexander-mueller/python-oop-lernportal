# SQL 01: Tabellen anlegen & Daten abfragen

Willkommen zum SQL-Modul! In dieser Lektion lernst du relationale Datenbank-Abfragen mit SQLite im Browser.

## 🎯 Lernziele
1. `CREATE TABLE` zur Definition von Tabellen und Datentypen (`INTEGER PRIMARY KEY`, `TEXT`, `REAL`)
2. `INSERT INTO` zum Einfügen von Datensätzen
3. `SELECT` mit `WHERE`, `ORDER BY` und `LIMIT`

## 🚀 Ausführung
Klicke in der Web-IDE auf **Code ausführen**, um deine SQL-Queries gegen die SQLite WebAssembly Datenbank auszuführen.
