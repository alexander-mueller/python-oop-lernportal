DNS 05: A- & AAAA-Records (IPv4 & IPv6 Dual-Stack)

Beherrsche die fundamentalen Forward-Lookup Records: IPv4 32-Bit (A) und IPv6 128-Bit (AAAA), Round-Robin Load Balancing und Dual-Stack Auditing.

🌐 1. Vorwärtsauflösung: A vs. AAAA

Über 95% aller DNS-Anfragen im Web betreffen A- und AAAA-Records. Moderne Webdienste müssen zwingend **Dual-Stack** erreichbar sein:

# BIND9 Zonendatei (db.it-praxisportal.de):
$ORIGIN it-praxisportal.de.
$TTL 3600

; IPv4 & IPv6 Dual-Stack für die Hauptdomain:
@       IN  A     188.245.100.5
@       IN  AAAA  2a01:4f8:c010:d::1

; Hostname www mit denselben Adressen:
www     IN  A     188.245.100.5
www     IN  AAAA  2a01:4f8:c010:d::1

⚖️ 2. Round-Robin DNS Lastverteilung

Durch Hinterlegen mehrerer A-Records unter demselben Namen rotiert der Nameserver die Antwortreihenfolge (Round-Robin):

# 3 Webserver-Knoten im Pool:
app     300 IN  A   192.0.2.11
app     300 IN  A   192.0.2.12
app     300 IN  A   192.0.2.13
⚠️ Wichtig für die IHK-Prüfung: Grenzen von Round-Robin DNS

DNS Round-Robin prüft keinen Server-Health-Status! Fällt Server 2 aus, sendet DNS weiterhin 33% der Nutzer auf die tote IP. Für Hochverfügbarkeit ist ein Hardware-/Cloud-Loadbalancer (Reverse Proxy) erforderlich.

📑 3. Cheat-Sheet: A- & AAAA-Syntax

Record Adressformat Bitbreite Beispiel
A Dotted-Decimal (IPv4) 32 Bit (4 Oktette) web IN A 192.0.2.1
AAAA Hexadezimal / Doppelpunkt (IPv6) 128 Bit (16 Oktette) web IN AAAA 2001:db8::1
