1. Warum SRV-Records? Das Problem klassischer A-Records

Ein A-Record liefert nur eine IP-Adresse. Läuft der LDAP-Server auf Port 389 oder 636? Welcher von drei DCs hat die höchste Rechenleistung? RFC 2782 SRV-Records lösen dies durch strukturierte Metadaten direkt in der DNS-Zone.

🏢 Analogie: Das Firmen-Telefonbuch mit Durchwahlen

Ein A-Record ist die Firmenadresse auf dem Briefkopf. Ein SRV-Record ist der Empfang mit Durchwahlliste: Er sagt dir, in welchem Büro (Host), auf welcher Durchwahl (Port) und wer zuerst abhebt (Priorität/Gewichtung).

2. Active Directory DNS-Discovery Struktur

SRV-Discovery in Microsoft Windows Server Umgebungen
; Active Directory Domain Controller Discovery
_ldap._tcp.dc._msdcs.corp.local.   600 IN SRV 0 100 389  dc01.corp.local.
_kerberos._tcp.dc._msdcs.corp.local. 600 IN SRV 0 100 88   dc01.corp.local.
_gc._tcp.corp.local.                 600 IN SRV 0 100 3268 dc01.corp.local.
