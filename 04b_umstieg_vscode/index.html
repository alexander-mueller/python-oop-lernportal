Umstieg von Thonny auf Visual Studio Code 🚀💻

Willkommen in der Profi-Entwicklungsumgebung! Lerne die besten Plugins, Shortcuts und Arbeitsabläufe kennen.

1. Warum wechseln wir von Thonny zu VS Code?

Thonny war für den Anfang genial: Es ist einfach, hat einen Variablen-Inspektor und man kann Zeile für Zeile durch ein Skript gehen.

Doch je größer deine Projekte werden (mehrere Dateien, Klassen, Tests und Git), desto mehr stößt Thonny an seine Grenzen. Visual Studio Code (VS Code) ist der weltweite Standard in der professionellen Softwareentwicklung.

🏎️ Vom Fahrschulauto zum Rennwagen:
  • Thonny ist das Fahrschulauto mit Doppelpedalen – perfekt für die ersten Fahrstunden auf dem Parkplatz.
  • VS Code ist ein modernes Sportauto mit Navi, Spurhalteassistent, Tempomat und Turbolader. Es hilft dir beim Tippen, findet Fehler automatisch und macht das Coden viel schneller!

Die 4 größten Vorteile von VS Code:

  • IntelliSense: Schlägt dir automatisch Methoden und Variablennamen vor (kein Vertippen mehr!).
  • Projekt-Ordner: Du siehst alle Dateien deines Projekts auf einen Blick in der Seitenleiste.
  • Integriertes Terminal: Führe Tests und Skripte direkt im Editor aus, ohne Fenster zu wechseln.
  • Tausende Erweiterungen: Passe VS Code mit Themes, Formatierern und Fehleranzeigen perfekt an dich an.

2. Das wichtigste Grundkonzept: "Ordner öffnen" (Open Folder)

⚠️ Wichtigster Unterschied zu Thonny:
In Thonny hat man meist nur eine einzelne Datei geöffnet (z.B. aufgabe.py).
In VS Code öffnet man immer den gesamten Projektordner (z.B. Aufgaben-Python)!

So öffnest du dein Projekt richtig:

  1. Starte Visual Studio Code.
  2. Klicke im Menü oben auf Datei → Ordner öffnen... (oder Strg + K, dann Strg + O / auf Mac: Cmd + O).
  3. Wähle den Hauptordner Aufgaben-Python aus und klicke auf Öffnen.
  4. Bestätige eventuell die Frage "Vertrauen Sie den Autoren?" mit Ja.

Jetzt siehst du links im Explorer alle Kapitelordner, Tests und Dateien sauber aufgelistet!

3. 🧩 Die unverzichtbaren Erweiterungen (Plugins)

Um Erweiterungen zu installieren, klicke ganz links in der Seitenleiste auf das Erweiterungs-Icon (die vier Quadrate mit einem fliegenden Würfel) oder drücke Strg + Shift + X (Mac: Cmd + Shift + X).

🐍

Python (von Microsoft)

Pflicht-Plugin! Aktiviert Syntax-Highlighting, Code-Ausführung, IntelliSense und Debugging.

⚡

Pylance (von Microsoft)

Macht die Autovervollständigung blitzschnell und warnt dich sofort bei falschen Typen.

🔍

Error Lens Geheimtipp!

Zeigt Fehler und Warnungen direkt als farbigen Text in der Codezeile an – kein Suchen im Terminal nötig!

🎨

Material Icon Theme

Verleiht Python-, HTML- und Git-Dateien im Explorer hübsche und bunte Symbole.

💬

Better Comments

Färbt Kommentare ein: # TODO: wird orange, # ! wird rot, # ? wird blau.

🪄

Black Formatter

Formatiert deinen Code beim Speichern (Strg+S) automatisch nach den offiziellen Python-Regeln.

4. 🖥️ Die Benutzeroberfläche im Überblick

  • Seitenleiste links:
    📁 Explorer: Dateibaum durchsuchen.
    🔍 Suche: Text im gesamten Projekt finden.
    🌿 Quellcodeverwaltung: Git Commits & Pushes.
    🧩 Erweiterungen: Neue Plugins installieren.
  • Das integrierte Terminal:
    Drücke Strg + ` (Taste links neben der Backspace-Taste / bzw. Strg + J).
    Hier kannst du direkt wie gewohnt deine Befehle tippen: 
    python3 test_all.py
  • Python-Interpreter auswählen:
    Unten rechts in der Statusleiste steht deine Python-Version (z.B. 3.11.x). Falls dort "Select Interpreter" steht, klicke darauf und wähle den empfohlenen Python-Pfad aus.

5. ⌨️ Die wichtigsten Tastenkombinationen (Shortcuts)

Mit diesen Shortcuts codest du wie ein echter Profi:

Aktion Windows / Linux macOS
💾 Datei speichern Strg + S Cmd + S
💻 Terminal öffnen / schließen Strg + ` (oder Strg + J) Cmd + ` (oder Cmd + J)
⚡ Command Palette (Alles suchen) Strg + Shift + P Cmd + Shift + P
🪄 Code automatisch formatieren Alt + Shift + F Option + Shift + F
✨ Nächstes gleiches Wort markieren Strg + D Cmd + D
🚀 Skript direkt ausführen Strg + F5 (oder Play-Button oben rechts) Cmd + F5
